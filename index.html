How the calculation works
The table uses one physical coordinate system for both the graphics and the shot solver. A standard 2.25-inch pool ball is used. Direct shots use ghost-ball collision geometry. One-rail banks use reflected-pocket geometry against the actual cushion centerline. The route shown on the table is the same route used by the calculation.

Real tables introduce additional variables such as speed, spin, throw, cloth, cushion response, pocket shelf depth, and table condition.
