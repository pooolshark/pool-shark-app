How the calculation works
The direct-shot solver uses the object-ball-to-pocket line and ghost-ball geometry. The bank solver reflects the target pocket across the selected cushion and finds the actual rail intersection. Proposed paths are checked before being displayed so an impossible route is not presented as a valid shot.

This is a geometric model, not a promise that every real-world bank will drop perfectly. Speed, spin, cloth, cushion response and throw can change a real shot.
