Accuracy / calculation
The table is modeled as a standard 2:1 pool table. Ball diameter is 2.25 inches. The cue-tip marker is scaled from an approximately 12.5 mm cue tip rather than an arbitrary screen pixel size. Direct shots use ghost-ball geometry. One-rail banks use reflected-pocket geometry and calculate the cushion intersection in table coordinates before rendering the result.

Real shots can require compensation for speed, spin, throw, cloth, cushion condition and pocket geometry.
