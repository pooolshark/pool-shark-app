Shot calculation
Standard 2:1 playing surface. Ball diameter: 2.25 inches. Direct shots use ghost-ball geometry. Bank shots use reflected-pocket geometry and calculate the actual cushion intersection before rendering the route. The visual table and calculation table use the same coordinate system.

Actual results can vary with speed, spin, throw, cloth, cushion condition, pocket shelf and pocket size.
